# ADNI 기반 뇌 연령(BAG) 및 취약 부위 3D 시각화 프로젝트

## 목적

이 프로젝트는 ADNI의 T1 MRI FreeSurfer 표형 지표를 이용해 정상 노화 기준의 뇌 연령을 Ridge 회귀로 예측하고, 연령 편향을 보정한 Brain Age Gap(BAG)을 산출합니다. 이후 CN, MCI, AD의 BAG 차이와 피질 취약 부위를 통계적으로 비교하고, 표준 뇌 표면에 집단별 및 RID별 3D 지도로 렌더링합니다.

## 실행 파일

- `ADNI_뇌연령_BAG_3D_분석.ipynb`: 전체 전처리, 학습, 검증, BAG, 통계, 3D 시각화를 실행하는 유일한 노트북입니다.
- `requirements.txt`: 권장 실행 환경입니다.

## 데이터 경로

노트북은 바탕화면이나 사용자 계정명을 코드에 고정하지 않습니다. 프로젝트 폴더를 찾은 뒤 내부 `01_원본데이터/ADNI_data.zip`에서 필요한 CSV를 추출합니다.

원본 ZIP은 ADNI 배포 제한 자료입니다. 프로젝트 외부 공유, 공개 저장소 업로드, 제3자 전달을 해서는 안 됩니다.

## 분석 설계

1. `_combat` FreeSurfer ROI, 성별, 교육연수, ICV를 사용합니다.
2. RID별 가장 이른 유효 T1 MRI 한 건을 선택합니다.
3. CN만으로 Ridge 모델을 학습하고, 연령·성별 층화 70/15/15 훈련·검증·테스트 분할을 사용합니다.
4. Ridge `alpha`는 훈련 CN 내부 5겹 교차검증으로 선택합니다.
5. 검증 CN에서 `raw predicted age = a + b × chronological age` 보정식을 추정한 뒤, 모든 분석 대상에 적용합니다.
6. `corrected BAG = corrected predicted brain age - chronological age`로 계산합니다. 절대값을 사용하지 않으므로 음수 BAG도 유지됩니다.
7. 독립 테스트, 부트스트랩 MAE 신뢰구간, 순열검정, 중첩 5겹 교차검증으로 성능과 과적합 위험을 확인합니다.
8. BAG 집단 비교에서는 실제 연령·성별·교육연수·ICV를 보정하고 Holm 다중검정 보정을 적용합니다.
9. 피질 68개 ROI에서 CN 기준 기대 두께 대비 얇아짐을 계산하고 FDR 보정 후 집단 3D 지도에 표시합니다.
10. 개인 지도에서는 각 RID의 피질 두께를 같은 나이·성별·교육연수·ICV를 가진 CN 훈련군 기준 기대 두께와 비교합니다. `개인 피질 노화 부담 z = -(관측 두께 - 기대 두께) / CN 잔차 표준편차`이며, 양수와 빨강이 클수록 얇아진 방향의 부담이 큽니다.
11. 개인 검색 결과에는 MRI와 가장 가까운 365일 이내의 CDR Global·CDR-SB와 DXSUM 기반 추적 진단 이력을 표시합니다. 이 값들은 BAG 모델 입력이나 성능 평가에 사용하지 않습니다.
12. `PHC_Diagnosis`는 Index MRI 촬영 시점의 ADNI 진단 단계입니다. 원본 코드 `1=CN(정상 인지)`, `2=MCI(경도인지장애)`, `3=AD(알츠하이머병)`을 개인 3D 결과에 직접 표시합니다.
13. 전처리 단계에서 Index MRI 코호트의 ComBat ROI 피어슨 상관행렬을 저장하고, 나이와의 절대 상관이 큰 상위 15개 ROI를 히트맵으로 표시합니다. 이는 변수 구조를 점검하기 위한 탐색 자료입니다.

## 중요한 해석 원칙

- Ridge만 사용한다는 연구 설계 제약 안에서 가장 좋은 `alpha`를 선택합니다. 이는 모든 가능한 알고리즘 중 최고 성능을 주장하는 것은 아닙니다.
- `05_취약부위_3D렌더링`의 지도는 표준 `fsaverage5` 표면에 표시하는 집단 통계 지도입니다. 개인의 실제 피질 표면 또는 진단 영상이 아닙니다.
- `06_RID별_개인_3D렌더링`의 지도는 선택한 RID의 FreeSurfer 부위별 수치를 표준 `fsaverage5`의 같은 구획에 투영한 개인별 정량 지도입니다. 개인의 실제 뇌 모양을 재구성한 지도는 아닙니다. 실제 개인 표면은 해당 RID의 FreeSurfer `surf/` 파일 또는 원본 T1 MRI가 있어야 렌더링할 수 있습니다.
- CDR Global은 전반적 인지·기능 저하의 임상 중증도(0=정상, 0.5=매우 경도, 1=경도, 2=중등도, 3=중증)이고, CDR-SB는 6개 영역의 합계 점수입니다. 이는 AD 진행 속도나 확정 진단을 뜻하지 않습니다.
- CDR이 없거나 MRI 시점에서 365일보다 멀면 개인 검색 결과에 `연결된 CDR 평가 없음`으로 표시합니다.
- ROI 상관 히트맵은 변수들이 함께 변하는 정도를 보여 줄 뿐, 인과관계나 Ridge 모델의 변수 가중치를 뜻하지 않습니다.
- 개인별 BAG와 피질 부담 지도는 연구용 지표입니다. 단독으로 질환을 진단하거나 치료 결정을 내리는 용도로 사용하면 안 됩니다.
- 해마와 뇌실은 피질 표면이 아닌 피질하 구조이므로, `해마_내은피질_측두엽_뇌실_통계.csv`에서 함께 확인합니다.
- ADNI 내부 검증은 외부 병원·다른 장비·다른 인구집단에서의 일반화를 보장하지 않습니다.

## 실행 방법

1. 이 프로젝트 폴더를 VS Code 또는 Jupyter 작업 폴더로 엽니다.
2. Python 환경에서 `python -m pip install -r requirements.txt`를 실행합니다.
3. `ADNI_뇌연령_BAG_3D_분석.ipynb`를 열어 **Run All**을 실행합니다.
4. 개인 지도가 필요한 경우 노트북 10장의 `RID 검색` 입력란에 RID를 입력하고 `개인 3D 지도 생성`을 누릅니다. 성별, 실제 나이, MRI 시점 진단, 보정 BAG, CDR, 추적 진단 이력, 상위 취약 부위, 좌·우반구 3D 지도가 노트북에 표시되고 HTML·CSV 파일이 `06_RID별_개인_3D렌더링`에 저장됩니다.
5. VS Code에서 검색 위젯이 보이지 않으면 노트북 10.2장의 `RID_TO_RENDER = 10` 숫자를 원하는 RID로 바꾼 뒤 실행합니다. 동일한 개인 3D 지도와 CSV·HTML 파일이 생성됩니다.
6. 노트북 10.3장에서 `RID 검색`은 한 명의 개인 결과를 생성하고, `비교 RID 목록`은 최대 4명의 RID를 쉼표로 입력해 비교합니다. 예: `2, 10, 24`.
7. 위젯이 보이지 않을 때는 10.4장의 `RID_LIST_TO_COMPARE = [2, 10]` 목록을 수정해 실행합니다. 비교 CSV, 보정 BAG 그래프, 좌·우반구 모델을 나란히 담은 HTML 대시보드가 생성됩니다.
8. HTML 파일은 브라우저로 열어 회전·확대·축소할 수 있습니다.
