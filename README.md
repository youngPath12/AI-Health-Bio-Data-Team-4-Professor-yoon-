## ADNI Brain Age Gap: 편향 보정 Ridge 파이프라인 + 집단별 3D 시각화

이 저장소의 `ADNI_Brain_Age_Gap_Ridge_BiasCorrected_3D_Colab.ipynb`는 뇌 MRI 구조 데이터로 "뇌가 실제 나이보다 얼마나 늙어 보이는지"를 계산하고, 정상(CN)·경도인지장애(MCI)·알츠하이머병(AD) 집단 간 차이를 3D로 시각화하는 Google Colab 노트북입니다. 이 문서는 코드를 처음 보는 사람도 프로젝트 전체 흐름과 각 결과를 어떻게 해석해야 하는지 알 수 있도록 작성했습니다.

## 1. 프로젝트 요약

**목표**: MRI에서 측정한 뇌 구조(해마 크기, 피질 두께, 뇌실 크기 등)만으로 "뇌 나이(brain age)"를 예측하는 모델을 만들고, `뇌 나이 − 실제 나이 = BAG(Brain Age Gap)`를 계산한다. BAG가 크다는 것은 뇌가 실제 나이보다 더 노화된 구조를 보인다는 뜻이며, 이 값이 알츠하이머병 진행 정도(CN → MCI → AD)와 함께 커지는지를 확인한다.

**한 줄 결론**: 이 노트북에서 학습한 모델로 계산한 보정 BAG는 CN(정상) → MCI(경도인지장애) → AD(알츠하이머병) 순서로 통계적으로 유의하게 증가했고, 그 증가는 주로 해마 위축, 내후각피질·측두엽 두께 감소, 뇌실 확장에서 비롯된다.

**왜 이런 작업을 하는가**: 나이 자체는 바꿀 수 없지만, "실제 나이보다 뇌가 얼마나 더 늙어 보이는가(BAG)"는 개인의 신경퇴행 정도를 요약하는 지표로 쓸 수 있다. 향후 이런 지표가 인지저하 조기 발견이나 위험군 선별에 보조적으로 쓰일 수 있는지를 탐색하는 것이 이 분석의 취지다. (다만 이 노트북 자체는 연구용이며, 개별 환자 진단 도구가 아니다 — 8번 항목 "한계" 참고.)

## 2. 배경 지식 (처음 보는 사람을 위한 용어 설명)

| 용어 | 설명 |
|---|---|
| **ADNI** | Alzheimer's Disease Neuroimaging Initiative. 알츠하이머병 연구를 위해 여러 병원에서 모은 대규모 공개 MRI/임상 데이터셋. |
| **T1 MRI** | 뇌의 구조(해부학적 모양)를 찍는 기본적인 MRI 촬영 방식. 기능이 아니라 "모양"을 본다. |
| **FreeSurfer** | T1 MRI 영상에서 해마, 피질 두께, 뇌실 등 수백 개의 뇌 구조 크기를 자동으로 측정해주는 표준 소프트웨어. 이 측정값들을 "ROI(Region of Interest, 관심영역) 값"이라 부른다. |
| **ComBat 조화(harmonization)** | 여러 병원·스캐너마다 MRI 기계 특성이 달라 측정값에 인위적인 차이가 생기는데, 이를 통계적으로 보정해 병원이 달라도 값을 비교할 수 있게 만든 처리. 이 노트북은 이미 ComBat 보정이 끝난 값(`*_combat` 컬럼)을 사용한다. |
| **CN / MCI / AD** | CN(Cognitively Normal, 정상인지), MCI(Mild Cognitive Impairment, 경도인지장애), AD(Alzheimer's Disease, 알츠하이머병). 인지 저하가 진행되는 단계 순서: CN → MCI → AD. |
| **RID** | ADNI 참가자 고유 ID. 한 사람이 여러 번 MRI를 찍은 경우 여러 방문(visit) 기록이 있다. |
| **Brain Age / BAG** | Brain Age = 모델이 MRI만 보고 추정한 "뇌의 나이". BAG(Brain Age Gap) = Brain Age − 실제 나이. 양수면 실제보다 뇌가 더 늙어 보인다는 뜻. |
| **Ridge 회귀** | 여러 입력 변수(여기서는 191개 ROI)가 서로 상관관계가 높을 때도 안정적으로 예측을 학습하는 선형 회귀 기법. (4절에서 자세히 설명) |
| **eTIV** | Estimated Total Intracranial Volume, 두개강 내 전체 용적(대략 두개골 안 공간의 크기). 사람마다 머리 크기가 달라서 생기는 차이를 보정하기 위한 공변량으로 쓴다. |
| **ANCOVA** | 공변량을 통제한 분산분석. 여기서는 나이·성별·두개강 용적이 같다고 가정했을 때도 CN/MCI/AD 간 BAG 차이가 유의한지를 검정한다. |

- **왜 "1인 1건(index MRI)"만 쓰는가**: 같은 사람이 여러 번 MRI를 찍으면, 그 사람의 데이터가 훈련 집합과 테스트 집합에 동시에 섞여 들어갈 위험이 있다(정보 누수, data leakage). 그러면 모델이 "새로운 사람"이 아니라 "이미 본 적 있는 사람"을 맞히는 셈이 되어 성능이 부풀려진다. 이를 막기 위해 참가자당 가장 이른 시점의 MRI 1건만 사용한다.
- **표준 관계 부속 파일**: `left.aparc.annot`, `right.aparc.annot` — FreeSurfer가 피질을 68개 구역(parcel)으로 나눈 경계 정보. 3D 뇌 표면 지도를 그릴 때 각 ROI 값을 뇌 표면의 어느 위치에 칠할지 알려준다.

## 4. 파이프라인 단계별 설명 (노트북 섹션 = 아래 목차와 1:1 대응)

### 0. 환경 준비
Colab에 기본으로 없는 패키지(`nilearn`, `nibabel`, `plotly`, `statsmodels` 등)를 설치하고, 그래프에 한글이 깨지지 않도록 폰트를 설정한다. 난수 시드(`RANDOM_SEED`)를 고정해 다시 실행해도 같은 결과가 나오게 한다.

### 1. 데이터 로드 및 Index MRI 확인
`adni_personal_modeling_cohort.csv`를 불러오고, RID가 중복되지 않는지(=1인 1건 원칙이 지켜졌는지) 검증한다. **해석**: "고유 RID 수"와 "행 수"가 같으면 정상이다.

### 2. 특징(feature) 정의
모델 입력으로 쓸 191개 ROI(해마, 편도체, 시상, 뇌간, 뇌실, 68개 피질 parcel의 두께·용적 등) + 성별(`PHC_Sex`) + eTIV를 정의한다. 교육이수(education) 변수는 현재 파일에 없어서 자동 감지만 해두고 이번 실행에는 빠진다(코드는 있으니 나중에 인구통계 파일을 합치면 자동으로 포함됨).

### 3. CN 개발 코호트 분할
뇌 나이 모델은 **정상인지(CN) 참가자에서만 학습**한다 (질병으로 인한 구조 변화가 없는 "정상 노화" 패턴을 배우기 위해). 나이 삼분위 × 성별로 층화해 훈련(70%) / 검증(15%) / 테스트(15%)로 나눈다. **왜 층화하는가**: 무작위로만 나누면 우연히 젊은 사람이 테스트 집합에 몰릴 수 있어, 나이·성별 분포를 각 집합에서 비슷하게 맞추기 위함이다.

### 4. 모델: Ridge 회귀 (고정 선택)
**Ridge 회귀를 처음부터 정해놓고 쓰는 이유**:
- 입력 ROI 191개는 서로 상관관계가 매우 높다(예: 좌뇌·우뇌 대칭 구조, 인접한 피질 영역). 이런 상황에서 일반 선형회귀는 계수가 불안정해지기 쉬운데, Ridge는 L2 정규화로 계수를 부드럽게 축소시켜 안정적인 예측을 만든다.
- 계수 하나하나의 크기와 부호를 그대로 해석할 수 있어(어떤 ROI가 나이 예측에 얼마나 기여하는지), 재현성과 설명력이 좋다.
- ElasticNet도 비교용으로 같이 학습해서 표로 보여주는데, Ridge와 성능이 거의 같다는 것을 확인해 "성능을 희생하지 않으면서 더 안정적인 선택"이라는 근거로 삼는다.

**결과 해석**: `cv_mae_years`(5-fold 교차검증 평균 오차, 년), `validation_mae_years`(검증 집합 오차)를 비교한 표가 나온다. 두 모델의 오차가 비슷하면 Ridge를 써도 성능 손해가 없다는 뜻이다.

### 5. 과적합 평가
"이 모델이 훈련 데이터만 외운 것은 아닌가?"를 확인하는 단계.
- **Train vs CV vs Validation vs Test MAE 비교표**: Train(자기 자신 예측)은 항상 오차가 가장 낮다. 문제는 그 차이가 얼마나 크냐다 — Train과 Validation/Test 오차가 크게 벌어지면 과적합을 의심해야 한다. 이 노트북에서는 그 격차가 완만해서(3~4년대 안에서 수렴) 심한 과적합은 아니라고 판단한다.
- **Learning curve**: 훈련 표본 수를 늘려가며 Train/CV 오차가 어떻게 변하는지 보여준다. 두 선의 간격이 표본이 늘수록 좁아지면, 데이터가 더 있으면 더 좋아질 여지가 있다는 뜻이고, 지금 모델이 극단적으로 과적합된 것은 아니라는 근거가 된다.
- **정규화 강도(alpha) 곡선**: alpha를 바꿔가며 CV 오차가 어떻게 변하는지 그린다. 최적 alpha가 탐색 범위의 끝이 아니라 중간 어딘가에 있으면, 정규화가 적절히 작동하고 있다는 뜻이다.
- **순열검정(permutation test)**: 나이 값을 무작위로 섞어서 모델을 다시 학습시키는 것을 200회 반복한다. 진짜 모델의 오차가 이 무작위 결과들보다 확실히 낮으면(p-value가 작으면), "모델이 우연이 아니라 실제 신호를 학습했다"고 말할 수 있다.

### 6. 연령 편향 보정 및 BAG 계산
**왜 보정이 필요한가**: brain-age 모델은 구조적으로 젊은 사람은 실제보다 늙게, 나이 든 사람은 실제보다 젊게 예측하는 경향이 있다(평균으로 회귀하는 통계적 현상, regression-to-the-mean). 이걸 그대로 두면 "젊은 사람은 다 BAG가 양수, 나이 든 사람은 다 BAG가 음수"처럼 나이 자체와 인위적으로 상관된 BAG가 나온다.

**보정 방법**: CN 검증 집합에서 `예측나이 = a + b × 실제나이` 관계를 구한 뒤, 그 역함수로 모든 사람의 예측 나이를 다시 계산한다. 그러면 보정된 BAG는 (이상적으로는) 실제 나이와 상관관계가 없어지고, "노화 이상 정도"만 남는다.

**BAG 계산식**: `보정 BAG = 보정된 예측 뇌나이 − 실제 나이`

**해석**: 보정 후 그래프에서 CN 테스트 집합의 점들이 기울기 0에 가까운 직선 주변에 흩어져 있으면 보정이 잘 된 것이다.

### 7. 집단 비교: CN(test) vs MCI vs AD
나이·성별·eTIV를 통제한 ANCOVA로 CN 대비 MCI, AD의 보정 BAG 차이를 검정한다.

**결과표 읽는 법**:
- `estimate_years`: MCI(또는 AD)가 CN보다 평균적으로 몇 년 더 "뇌가 늙어" 보이는지.
- `CI95_low` / `CI95_high`: 95% 신뢰구간. 이 구간이 0을 포함하지 않으면 통계적으로 유의미한 차이다.
- `p_value_holm`: 여러 번 비교(MCI-CN, AD-CN)를 하면서 생기는 우연한 유의성을 보정한 p-value. 0.05보다 작으면 유의하다고 본다.

**이 노트북에서 재현된 수치** (실행할 때마다 데이터 분할 난수는 고정돼 있어 거의 동일하게 나온다):

| 집단 | 보정 BAG 평균(년) | 해석 |
|---|---:|---|
| CN (테스트) | 약 −1.4 | 정상군은 실제 나이보다 오히려 살짝 젊게 예측 (보정이 잘 됐다는 신호) |
| MCI | 약 +4.8 | 경도인지장애군은 실제보다 뇌가 약 4.8년 더 늙어 보임 |
| AD | 약 +13.4 | 알츠하이머군은 실제보다 뇌가 약 13.4년 더 늙어 보임 |

세 집단 모두 통계적으로 유의미하게 차이가 나며(p < 0.001 수준), **CN < MCI < AD** 순서가 명확하게 관찰된다.

### 8. 지역별(ROI) 노화 부담 Z-score
"어느 뇌 부위가 이 BAG 증가를 만들어내는가?"를 보기 위한 단계. CN 훈련 집합으로 각 ROI에 대해 "이 나이·성별·두개강 크기라면 정상적으로 이 정도 크기여야 한다"는 규준 모델을 만들고, 실제 값이 거기서 얼마나 벗어났는지를 Z-score로 계산한다.

- 피질 두께/회백질 용적: **값이 작을수록** 노화 부담이 크다고 정의(위축).
- 뇌실/CSF: **값이 클수록** 노화 부담이 크다고 정의(확장).
- 부호를 통일해서, "부담 Z-score가 클수록 나쁜 방향"으로 항상 같은 의미가 되게 만들었다.

**결과 해석**: CN < MCI < AD로 갈수록 부담 Z-score가 커지는 부위가 진짜 알츠하이머병 관련 위축 부위다. 이 노트북에서 확인된 상위 부위는 **해마(hippocampus)**, **편도체(amygdala)**, **내후각피질(entorhinal cortex)**, **중측두이랑 등 측두엽(temporal lobe)**, **가쪽뇌실(lateral ventricle)** 이다. 이는 실제 알츠하이머병 신경병리학과 일치하는 결과다(해마-내후각피질은 가장 먼저, 가장 크게 위축되는 것으로 알려진 부위).

### 9. 집단별(CN → MCI → AD) 3D 시각화 (Plotly)
좌·우 피질 표면(빨간색이 진할수록 피질이 얇아진 부담이 큼)과 해마·편도체·뇌실·뇌간 등 피질하 구조(구슬 크기·색이 클수록 부담이 큼)를 한 화면에 그린다. 위쪽 버튼이나 아래쪽 슬라이더로 CN/MCI/AD를 전환하며 비교할 수 있고, 마우스로 회전·확대할 수 있는 HTML로 저장된다.

### 9-1. (고급) PyVista/VTK 기반 입체 렌더링
Plotly보다 더 사실적인 음영(smooth shading, 뇌 고랑·이랑의 실제 굴곡 음영, 물리기반 재질감)을 적용해 CN/MCI/AD 세 개를 나란히 회전 비교할 수 있게 만든 버전. 카메라가 세 화면에서 함께 움직이도록 연동되어 있어, 하나를 돌리면 셋 다 같이 돈다. 정지 이미지(PNG)나 360도 회전 동영상(MP4)으로 저장하는 코드도 포함되어 있다(가상 디스플레이 `pv.start_xvfb()` 필요).

**3D 지도 보는 법**:
- 피질 색(빨강): CN 대비 피질이 얇아진 정도(Z-score). 진할수록 더 얇음(=더 위축됨).
- 구슬(피질하 구조): 해마·편도체·시상·조가비핵·가쪽뇌실·3뇌실·4뇌실·뇌간의 **근사 위치**에 놓은 표식이며, 실제 세그멘테이션 모양이 아니다. 크고 진할수록 그 구조의 위축(회색질) 또는 확장(뇌실) 부담이 크다는 뜻.

## 7. 이 모델을 어떻게 신뢰할 수 있는가 (검증 요약)

- **독립 테스트 집합**: 모델 학습·모델 선택에 전혀 쓰이지 않은 CN 15%를 따로 떼어 최종 성능을 평가했다.
- **참가자 단위 분할**: RID 기준으로 나눠서 같은 사람이 여러 집합에 섞이지 않게 했다(정보 누수 방지).
- **순열검정**: 나이를 무작위로 섞은 200회 반복보다 실제 모델이 유의하게 더 정확함을 확인했다(5절).
- **공변량 보정**: 집단 비교(CN/MCI/AD)에서 나이·성별·두개강 용적을 통제해, 단순한 인구통계 차이가 아니라 BAG 자체의 차이를 봤다(7절).

## 8. 한계 및 주의사항

- **교육이수(education) 미포함**: 현재 입력 파일(FreeSurfer 구조 ROI)에는 교육 연수 변수가 없다. 코드에는 있으면 자동으로 포함하는 로직이 들어있어, ADNIMERGE 인구통계 자료를 RID·방문일 기준으로 병합하면 별도 수정 없이 반영된다.
- **피질하 구조 3D 글리프(구슬)는 개략적 표식**: 실제 세그멘테이션 형상이 아니라, 부담 크기(Z-score)를 눈으로 비교하기 위해 근사 해부학적 위치에 그린 것이다.
- **개인 진단 도구 아님**: 이 파이프라인은 연구용 집단 수준 분석이다. 개별 환자의 확정적 임상 진단, 치료 결정, 위험도 판정에 사용해서는 안 된다.
- **인과관계 아님**: BAG나 ROI 부담이 크다는 것이 "그 부위가 원인적으로 인지저하를 일으켰다"는 증거는 아니다. 관찰된 연관성이다.
- **모델 성능의 한계**: MAE(평균절대오차)가 약 4년 수준으로, 개인별 뇌 나이를 정밀하게 맞추는 정확도는 아니며 집단 수준 비교에 적합한 수준이다.
