# ADNI Brain Age Gap V2 프로젝트

## 프로젝트 목적

이 프로젝트는 ADNI의 구조적 T1 MRI FreeSurfer ROI 자료를 사용하여 정상인지(CN) 참가자의 실제 연령을 예측하는 brain-age 모델을 만들고, 예측 연령과 실제 연령의 차이인 Brain Age Gap(BAG)을 분석합니다.

`BAG = 예측 뇌 연령 - 실제 연령`

- 양수 BAG: 실제 연령보다 뇌가 더 늙어 보이는 방향
- 음수 BAG: 실제 연령보다 뇌가 더 젊어 보이는 방향

분석은 CN에서 모델을 학습한 뒤 MCI 및 AD 집단의 BAG 차이, MCI의 AD 전환 연관성, ROI별 피질 노화 연관성을 확인합니다.

## 데이터와 전처리

입력 자료는 `ADSP_PHC_T1_FS_22Jan2026.csv`의 ComBat 보정 FreeSurfer ROI입니다. 피질 두께·부피, 피질하 구조 부피, 뇌 전체 부피와 ICV를 포함합니다.

전처리 원칙은 다음과 같습니다.

1. 분석에 필요한 RID, 촬영일, 연령, 성별, 진단, ROI가 모두 있는 방문만 사용합니다.
2. 한 참가자의 여러 방문이 서로 다른 학습/검증/테스트 집합에 섞이지 않도록, 첫 번째 적격 T1 방문만 기본 분석에 사용합니다.
3. CN 참가자를 연령 삼분위와 성별로 층화하여 훈련·검증·독립 테스트 집합으로 분할합니다.
4. 연령, 성별, ICV의 유효 범위와 ROI 결측·비수치 값을 점검합니다.
5. 입력 ROI는 이미 ComBat 보정된 변수만 사용합니다. 스캐너 정보로 다시 보정하여 편향을 되돌리는 작업은 하지 않습니다.

전체 ADNI 폴더에는 별도 MRI/FreeSurfer QC 자료가 있지만, 현재 PHC T1 입력 행과 모든 참가자에서 안전하게 일대일 연결되는 QC 결과는 아닙니다. 따라서 일부 참가자만 남기는 임의의 QC 필터는 기본 모델에 적용하지 않았습니다. 이 제한은 노트북과 결과 문서에 명시되어 있습니다.

## 모델 설계

- 학습 대상: 정상인지(CN) 참가자
- 입력: 191개 ComBat ROI, 성별, ICV
- 후보 모델: Ridge, Elastic Net
- 선택 기준: CN 검증 집합의 MAE
- 최종 선택: Elastic Net
- 평가: 학습·모델 선택에 사용하지 않은 독립 CN 테스트 집합
- BAG 보정: 검증 집합에서 추정한 연령 편향 보정식을 적용

## 주요 결과

독립 CN 테스트 성능은 다음과 같습니다.

| 지표 | 값 |
|---|---:|
| MAE | 4.17년 |
| RMSE | 5.30년 |
| R2 | 0.445 |
| R2 순열검정 p값 | 0.001996 |
| MAE 순열검정 p값 | 0.001996 |

R2는 실제 연령 변동 중 모델이 설명하는 비율입니다. `R2 = 0.445`는 약 44.5%를 설명한다는 뜻입니다. R2 자체가 p값은 아니지만, 500회 연령 순열검정에서 실제 R2와 MAE가 우연 기준보다 유의하게 우수했습니다.

이 성능은 연구용 집단 수준 분석에 유의한 예측 성능이지만, 개인 단위의 임상 진단 또는 치료 결정을 위한 도구로 해석하면 안 됩니다.

## 3D 피질 지도 해석

3D HTML 파일은 회전·확대·축소할 수 있는 좌/우 반구 피질 지도입니다.

- 빨강: BAG가 증가할수록 피질 두께 감소와 더 강하게 연관된 부위
- 파랑: 반대 방향 연관성
- 흰색 선: FreeSurfer 피질 부위 경계

이 지도는 동일한 ROI로 학습된 모델의 연관성 지도입니다. 개인 MRI의 병변 위치, 개인별 진단 결과, 또는 BAG가 특정 부위를 인과적으로 노화시킨다는 증거는 아닙니다.

## R2 향상 검토 결과

현재 데이터 내에서 다음 방법을 별도로 확인했습니다.

| 방법 | 검증 R2 | 독립 테스트 R2 |
|---|---:|---:|
| 기존 Elastic Net | 0.507 | 0.445 |
| 훈련 CN의 반복 방문 추가 | 최대 0.421 | 평가 생략 |
| Random Forest | 0.518 | 0.433 |

반복 방문을 학습에 더 넣거나 Random Forest를 사용하는 방법은 독립 테스트 R2를 높이지 못했습니다. 따라서 현재의 T1-only, 첫 방문, 독립 CN 테스트 설계에서는 기존 Elastic Net 결과를 유지하는 것이 타당합니다.

DTI·PET·다른 MRI 파생 지표를 정확히 촬영 단위로 연결해 새 멀티모달 모델을 만들면 성능 향상 가능성은 있습니다. 그러나 이는 대상자 수와 포함 기준이 달라지는 별도 모델이며, 현재의 T1-only BAG와 직접 비교할 수 없습니다. 진단명, 인지점수, 방문 차수처럼 BAG 해석을 훼손하거나 정보 누출을 만들 수 있는 변수는 입력에 사용하지 않습니다.
