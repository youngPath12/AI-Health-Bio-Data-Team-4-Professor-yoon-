# ADNI 기반 뇌 연령(BAG) 측정 및 취약 부위 3D 시각화

> ADNI T1 MRI의 FreeSurfer 구조 지표로 정상 뇌 노화 패턴을 학습하고, 연령 편향을 보정한 Brain Age Gap(BAG)과 피질 취약 부위를 분석·시각화하는 재현 가능한 머신러닝 프로젝트입니다.

## 프로젝트 개요

이 프로젝트는 ADNI의 ADSP PHC ComBat 보정 FreeSurfer ROI 데이터를 사용합니다. 인지적으로 정상인 참가자(CN)만으로 실제 나이를 예측하는 Ridge 회귀 모델을 학습한 뒤, 고정된 모델을 CN·MCI·AD 집단에 적용해 연령 편향이 보정된 BAG를 계산합니다.

이후 실제 연령, 성별, 교육연수, 두개강내총용적(ICV)을 고려한 집단 간 BAG 차이와 피질 취약 부위를 통계적으로 비교합니다. 집단별 결과와 RID별 개인 결과는 표준 `fsaverage5` 뇌 표면에 3D 지도로 표시합니다.

### 주요 연구 질문

- 실제 연령, 성별, 교육연수, ICV를 보정한 뒤에도 MCI와 AD 집단은 CN보다 높은 BAG를 보이는가?
- CN 기준 기대 피질 두께와 비교했을 때 MCI와 AD 집단에서 더 취약한 피질 부위는 어디인가?
- 독립 테스트와 중첩 교차검증에서 Ridge 뇌 연령 모델의 성능과 과적합 위험은 어떠한가?

> 이 프로젝트의 BAG, CDR 정보, 통계 결과 및 3D 지도는 연구용입니다. 개인의 질환을 진단하거나 치료 결정을 내리는 용도로 사용할 수 없습니다.

## Brain Age Gap이란?

```text
보정 BAG = 연령 편향이 보정된 예측 뇌 나이 - 실제 나이
```

- 양의 BAG: MRI 구조 패턴이 같은 실제 나이의 CN 기준보다 상대적으로 더 고령의 뇌 구조와 유사함을 뜻합니다.
- 음의 BAG: MRI 구조 패턴이 같은 실제 나이의 CN 기준보다 상대적으로 더 젊은 방향임을 뜻합니다.
- BAG는 정상 기준 모델에서 벗어난 정도를 나타내는 연속형 연구 지표입니다. 치매 진단, 인과적 바이오마커, 미래 위험 점수 또는 개인의 노화 속도를 직접 측정한 값이 아닙니다.

```text
ADNI_data.zip

      ↓

      ↓

      ↓
```

### 코호트 구성 원칙

- 실제 나이 40–100세, 성별 코드 1 또는 2, 교육연수 0–30년, ICV가 0보다 큰 값을 유효 범위로 사용합니다.
- 필수 입력이 모두 유효한 검사만 남긴 뒤 RID별 가장 이른 T1 MRI 한 건을 Index MRI로 선택합니다.
- `PHC_Diagnosis` 원본 코드는 `1=CN`, `2=MCI`, `3=AD`로 사용합니다.
- ComBat ROI의 극단값은 MAD 기반으로 감사표에 기록하지만 자동 삭제하지 않습니다.
- RID와 촬영일은 개인 식별·정렬에만 사용하며 모델 입력에는 포함하지 않습니다.
- DXSUM 및 CDR은 개인 결과의 임상 맥락을 보여 주기 위한 자료이며 Ridge 모델의 입력이나 성능 평가에는 사용하지 않습니다.

## 모델 학습과 검증

### 입력과 목표값

- 목표값: T1 MRI 촬영 시 실제 연령 `PHC_Age_T1`
- 모델 입력: ICV를 제외한 모든 `*_combat` FreeSurfer ROI, 성별, 교육연수, ICV
- 주 모델: Ridge regression

구조 MRI ROI는 서로 강하게 연관될 수 있습니다. Ridge 회귀는 계수의 크기를 규제해 이러한 다중공선성에 비교적 안정적으로 대응하며, 표 형식 신경영상 데이터에서 재현하기 쉽습니다.

### 데이터 누수 방지

- CN 참가자만 정상 노화 기준 모델의 학습, 하이퍼파라미터 선택 및 연령 편향 보정에 사용합니다.
- RID별 Index MRI 한 건만 사용하므로 같은 참가자의 반복 촬영이 여러 분할에 들어가지 않습니다.
- CN은 연령·성별 층화 기준으로 train 70%, validation 15%, independent test 15%로 나눕니다.
- Ridge `alpha`는 train CN 내부 5겹 교차검증으로만 선택합니다.
- 연령 편향 보정식은 validation CN에서만 추정하고 test·MCI·AD에는 같은 식을 적용합니다.
- independent test는 최종 성능 평가에 사용합니다.

### 성능 및 과적합 점검

- train, validation, independent test의 MAE·RMSE·R²
- 독립 테스트 MAE의 부트스트랩 95% 신뢰구간
- 훈련 연령을 섞은 500회 순열검정
- 외부 5겹 평가와 내부 alpha 탐색을 결합한 중첩 5겹 교차검증
- 훈련·독립 테스트·중첩 교차검증 성능 비교

실행 결과의 주요 수치는 `07_실행환경_도움말/분석결과_자동요약.md`에 자동 저장됩니다. README에는 특정 실행의 수치를 고정해 적지 않아 데이터나 노트북이 갱신되어도 오래된 결과가 남지 않도록 했습니다.


## 정상 뇌 나이 예측에 기여한 MRI ROI

Ridge 모델은 CN train의 실제 나이를 예측하도록 각 MRI ROI와 인구학적 입력의 계수를 함께 학습합니다. 현재 노트북은 학습된 표준화 Ridge 계수를 정리하여 다음 파일에 저장합니다.

`03_모델학습_검증결과/Ridge_변수별가중치.csv`

절대 가중치가 큰 변수는 **현재 모델의 다른 입력들을 함께 고려했을 때** 예측값 변화에 더 크게 관여한 변수입니다. 계수의 부호는 해당 표준화 변수가 증가할 때 예측 뇌 나이가 증가하는지 또는 감소하는지를 나타냅니다.

### ROI 가중치 읽는 법

- 양의 계수: 다른 입력이 같을 때 해당 값의 증가가 더 높은 예측 뇌 나이와 연결되는 방향입니다.
- 음의 계수: 다른 입력이 같을 때 해당 값의 증가가 더 낮은 예측 뇌 나이와 연결되는 방향입니다.
- 절대 가중치: Ridge 모델 안에서의 상대적인 예측 기여 정도를 살펴보는 지표입니다.
- 피질 두께·회백질·해마 등의 감소와 뇌실·백질 고신호의 증가는 일반적인 노화 방향과 함께 해석할 수 있지만, ROI 종류와 단위 및 계수의 조건부 성격을 반드시 고려해야 합니다.

### 해석 시 주의

Ridge 계수는 모든 표준화 변수를 동시에 넣은 조건부 예측 가중치입니다. ROI들 사이의 높은 상관 때문에 관련 정보가 여러 계수에 나뉠 수 있고, 규제 강도 `alpha`에 따라서도 값이 달라집니다. 따라서 절대 가중치가 가장 큰 ROI를 질병의 원인, 독립 위험인자 또는 개인 진단 부위로 해석해서는 안 됩니다.

이전 README에 있던 고정된 ROI 순위와 MAE 증가량은 현재 노트북이 생성하는 Ridge 계수 결과와 평가 방식이 달라 그대로 싣지 않았습니다. 최신 순위는 해당 실행에서 생성된 `Ridge_변수별가중치.csv`를 기준으로 확인합니다.

## BAG 집단 비교

CN을 기준으로 MCI와 AD의 보정 BAG 차이를 비교합니다. 실제 연령, 성별, 교육연수 및 ICV를 공변량으로 포함하며, MCI-CN과 AD-CN 두 대비의 p값에는 Holm 보정을 적용합니다.

```text
corrected BAG ~ diagnosis + chronological age + sex + education + ICV
```

보정 BAG는 절대값으로 바꾸지 않으므로 음수 값도 그대로 유지합니다.

## 취약 부위 분석

68개 피질 두께 ROI 각각에 대해 CN 훈련군에서 실제 연령·성별·교육연수·ICV를 고려한 기대 피질 두께를 추정합니다.

```text
개인 피질 노화 부담 z
= -(관측 피질 두께 - CN 기준 기대 피질 두께) / CN 잔차 표준편차
```

값이 클수록 같은 공변량 조건의 CN 기준보다 피질이 더 얇은 방향입니다. 집단별 ROI 통계에는 Benjamini-Hochberg FDR 보정을 적용합니다.

해마 용적, 내후각피질·하측두엽 두께 및 뇌실 용적은 별도의 우선 관심 ROI 표로 저장합니다. 해마와 뇌실은 피질 표면 구조가 아니므로 3D 피질 지도에서 직접 표현하지 않습니다.

## 3D 시각화

### 집단별 지도

MCI-CN과 AD-CN의 피질 취약 부위 효과크기를 표준 `fsaverage5` 표면에 표시합니다.

- 빨강: CN보다 피질 얇아짐 부담이 큰 방향
- 파랑: CN보다 피질 얇아짐 부담이 작은 방향
- 흰 선: Desikan-Killiany 피질 구획 경계

### RID별 개인 지도

RID를 입력하면 다음 정보가 함께 생성됩니다.

- 실제 나이, 성별, 원시·보정 예측 뇌 나이와 보정 BAG
- MRI 시점 `PHC_Diagnosis`와 DXSUM 기반 추적 진단 이력
- MRI와 가장 가까운 365일 이내 CDR Global·CDR-SB
- CN 훈련군 기준 개인 피질 노화 부담 점수와 상위 취약 부위
- 좌·우반구 3D HTML 지도

여러 RID를 최대 4명까지 입력하면 BAG 비교 그래프와 좌·우반구 모델을 나란히 배치한 HTML 대시보드를 생성합니다.

> 집단 및 개인 지도는 FreeSurfer의 부위별 수치를 표준 `fsaverage5` 표면의 같은 구획에 투영한 정량 지도입니다. 참가자의 실제 MRI 표면이나 개인 고유의 뇌 형태를 재구성한 영상이 아닙니다. 실제 개인 표면을 렌더링하려면 해당 RID의 원본 T1 MRI 또는 FreeSurfer `surf/` 파일이 필요합니다.

## 해석과 한계

- 이 연구는 횡단면 관찰 분석이므로 인과관계나 개인별 뇌 노화 속도를 증명할 수 없습니다.
- Ridge만 사용한다는 설계 안에서 최적의 `alpha`를 선택한 것이며, 모든 가능한 알고리즘 중 최고 성능을 주장하지 않습니다.
- Ridge 계수는 모든 표준화 입력을 함께 고려한 조건부 예측 가중치입니다. 특정 ROI의 계수만으로 질병 원인이나 독립 위험인자를 판단할 수 없습니다.
- ROI 상관 히트맵은 변수들이 함께 변하는 정도를 보여 주는 탐색 자료이며, 인과관계나 Ridge 변수 가중치를 뜻하지 않습니다.
- `PHC_Diagnosis`와 DXSUM 진단은 임상 라벨이며 병리학적으로 확정된 알츠하이머병과 동일한 의미로 단정할 수 없습니다.
- CDR Global은 전반적인 인지·기능 저하 중증도이고 CDR-SB는 6개 영역 점수의 합입니다. CDR은 AD 진행 속도나 확정 진단을 직접 의미하지 않습니다.
- ComBat 조화는 다기관 기술 차이를 줄이지만 조화 절차 자체도 연구의 제한점입니다.
- ROI 수준 결과를 voxel 수준 위치 정보처럼 해석할 수 없습니다.
- ADNI 내부 검증은 외부 병원, 다른 장비 또는 다른 인구집단에서의 일반화를 보장하지 않습니다.
